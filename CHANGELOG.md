## [1.0.0] - 2026-08-23

### Added
- HomeWork: introductory grid-world exercises with a random policy and a tabular Q-learning agent with terminal animation.
- TP1: introduction to reinforcement learning using the `CartPole-v1` environment.
- TP2: Q-learning applied to the `FrozenLake-v1` environment.
- TP3: Q-learning vs. SARSA comparison on a custom traffic-light simulation environment.
- TP4: PPO (Proximal Policy Optimization) applied to the `Taxi-v3` environment.
- Video demonstrations and result plots for each lab.
