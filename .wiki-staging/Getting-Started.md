# Getting Started

## Prerequisites

- Python 3.10+

## Installation

```bash
git clone https://github.com/Bosaj/Reinforcement-Learning-Labs.git
cd Reinforcement-Learning-Labs
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install jupyter
```

Key dependencies: Gymnasium, NumPy, Matplotlib, pandas.

## Running the labs

```bash
jupyter notebook
```

Open any of `TP1/TP1.ipynb`, `TP2/TP2.ipynb`, `TP3/TP3.ipynb`, or `TP4/TP4.ipynb`. Each `TPx` folder also includes a demo video (`.mp4`) and a result screenshot (`.png`) of the trained agent, generated by running that notebook.

The `HomeWork` scripts are plain Python and run directly:

```bash
python HomeWork/HomeWork.py
python HomeWork/HomeWorkAnimation.py
```

## How CI validates the project

[`.github/workflows/ci.yml`](../.github/workflows/ci.yml) runs on every push/PR to `main`:

- Installs dependencies from `requirements.txt`.
- Validates that every `.ipynb` file is structurally well-formed (via `nbformat`).
- Lints the `.py` scripts with `flake8` (non-blocking, style feedback only).

CI does not execute full agent training — Q-learning over thousands of episodes and PPO over tens of thousands are too slow for a hosted runner without a GPU. It guards against broken notebooks and import errors, not against a regression in learned policy quality.
